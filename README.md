# ことり — Instagram投稿づくり

日本語の初心者向け投稿構成ツールです。外部API・外部ライブラリなしで、入力をテンプレートに当てはめて案を作ります。AIによる生成ではありません。入力内容はサーバーへ送信・保存しません。

## 起動

Node.js 20以上で、リポジトリのディレクトリから実行します。依存パッケージのインストールは不要です。

```sh
npm start
```

ブラウザでポート3000のアプリを開きます。ポート変更は `PORT=3001 npm start` で指定できます。

## 使い方

投稿テーマ・ターゲットを入力し、目的を選択して、フィード／リールを選択して「構成案を作成する」を押します。「入力例を使ってみる」で試せます。

フィード：表紙タイトル、5ページの見出しと本文、最後のCTA、キャプション。
リール：冒頭3秒のフック、30秒・5シーンのテロップと素材案と秒数、最後のCTA、キャプション。

コピー機能はブラウザの権限に依存します。使えない場合はコピー用の文章を選択してコピーできます。投稿前に事実確認し、具体例や表現を調整してください。

## 確認

```sh
npm test
```

生成内容・必須入力・形式を検証します。画面では入力例で両形式を生成し、コピーと狭い画面の表示を確認してください。

## インストールなしでブラウザで確認

`instagram-tool.html` はスタイルとプログラムをまとめた単体ファイルです。ダウンロードしてダブルクリックするとブラウザで開けます。インターネット接続やNode.jsは不要です。「入力例を使ってみる」→「構成案を作成する」で試してください。リールに切り替えて再度作成すると動画向けの案を確認できます。コピー権限がないブラウザではコピー用テキスト欄を表示します。

index.html と instagram-tool.html はどちらも直接開けます。画面テンプレート scripts/page-template.html、style.css、generator.js、app.js を変更した後は `npm run build` で両方のHTMLを更新してください。

目的は「知ってもらいたい」「保存してもらいたい」「共感してもらいたい」「フォローにつなげたい」「問い合わせ・申込みにつなげたい」「その他（自由入力）」から選べます。「その他」を選んだ場合だけ、目的の自由入力が必要です。

## v3：詳しいテーマと画像提案

テーマは改行入力できます。1行目にテーマ、2行目以降に伝えたいポイントを記入すると、構成案に反映します。任意の「画像のデザインを指定する」で雰囲気・色・見本の説明を指定できます。参考URLは記録のみで、リンク先の読み込みや画像解析はしません。ページ・シーンごとに画像のアイデアと共通ガイドを表示します。画像ファイルは生成しません。直接開く最新版は `instagram-tool-v3.html` です。
